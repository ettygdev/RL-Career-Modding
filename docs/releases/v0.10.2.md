# RLCareer Overhaul v0.10.2

This release includes the changes shipped since **v0.9.14**, the previous public version. Download **RLCareer-Overhaul.exe** and place it next to **RL Career Hub.exe**, replacing the older launcher. The match integration is included.

## Hub compatibility and launcher

- The launcher now accepts **RL Career Hub 0.2.0-beta.34**, alongside beta.33.
- Quick Chat now accepts the Hub’s line-ending change while still verifying the tactician file’s contents. The installer preserves the original line endings and supports restoration.
- Improved the Overhaul and Modifier badge integration and installed-version detection. The combined badge appears when Modifier is loaded.
- Added a dedicated Overhaul section in Settings, an expandable changelog on the Hub’s home screen, and a GitHub update prompt with executable integrity verification.
- Hid console windows for the targeted helper processes. Existing launchers and Steam shortcuts can keep the same executable filename.

## Competitive bot gameplay

- Focused the mechanics set on competitive touches, carries, passes, redirects, flicks, double taps, flip resets, ceiling plays, defense and recoveries. Removed dedicated scripted freestyle routines and pinches from the active path.
- Improved first-touch setup selection. Bots can plan a playable touch before contact, follow it with a carry or reset, or contest possession when the planned continuation is unavailable.
- Refined reset approaches, flip confirmation and reset pops. Added earlier wheel alignment, follow-up aiming and coordinated roll, pitch, yaw and boost. Surface recoveries can use a wavedash when an available dodge and suitable landing permit it.
- Improved aerial passing options, including a teammate pre-jumping an advanced pass. Adjusted kickoff selection, team spacing, shot accuracy, boost pickup approaches and defensive recovery.
- Reused timestamped RLBot ball prediction for Ripple and Nexto. Aerial first touches and carries use live hitbox dimensions. RocketSim can validate a limited set of contact candidates, with geometric fallback when needed.
- Connected all eight individual ratings to match behavior. Revised bump and demolition selection, and added avoidance for some predictable collisions.
- Refined planning using annotated and full-match replay reviews. Optional local diagnostics record missed contacts. Physical consistency and conversion rates are still being tuned.

## Career progression, scouting and equipment

- Added a technical training picker opened from the player card. Choose up to three exercises per player per week, view the affected attributes and develop them using the Hub’s progression curve. Mental training remains separate.
- Organized the equipment shop by category and brand, with models sorted by rating. Expanded the model catalogue while preserving existing purchases.
- Improved cosmetic thumbnail caching and fallback lookup. Expanded title support for future RLCS seasons and repeat World Champions.
- Extended simulated match calculations to reflect the eight player attributes and other career effects on team strength.

## Match controls, replays and presentation

- Reworked configurable preset Quick Chat for the four D-pad directions. Team orders and requests have separate categories, and categories or the entire feature can be disabled. Bots use contextual calls and respond to supported instructions. The D-pad is reserved for chat while the mod’s Quick Chat is enabled.
- Added support for detecting the native Rocket League replay-save request and exporting the replay at the end of a career match. F9 remains available as a fallback.
- Retained the compact played-match HUD, spectator broadcast HUD, pro camera profiles, post-game and series-finale scoreboards, music, tactical timeouts and referee-managed technical pauses.

See the [feature guide](https://github.com/ettygdev/RLCareer-Overhaul/blob/v0.10.2/README.md) for the full inventory of current features and installation instructions. The [source snapshot](https://github.com/ettygdev/RLCareer-Overhaul/tree/v0.10.2/Overhaul) includes the launcher, overlays, career systems and bot integration. The experimental PPO model is separate from this release.

**Validation.** The launcher started on Hub beta.34 and confirmed that Overhaul loaded. The Quick Chat installer was tested against the beta.34 tactics file, including byte-for-byte restoration. Full career and match validation on beta.34 is still pending.
